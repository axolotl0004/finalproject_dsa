GAMEHUB - DEMONSTRATION SCRIPT

Use this as a quick guide when presenting.

1. SHOW INVENTORY
   Choose 1.
   Explain:
   "The inventory is stored using a linked list. Each node contains
   a product and a pointer to the next product."

2. SEARCH BY NAME
   Choose 2.
   Enter:
   Portal
   Explain:
   "This is linear search because the program checks the products
   one at a time."

3. SEARCH BY ID
   Choose 3.
   Enter:
   103
   Explain:
   "This uses a binary search tree. IDs smaller than a node go left
   and larger IDs go right."

4. FILTER BRAND
   Choose 4.
   Enter:
   Valve
   Explain:
   "This filters the linked-list inventory by brand."

5. SORT
   Choose 5.
   Explain:
   "This uses Bubble Sort to arrange the games by price."

6. BUY
   Choose 6.
   Enter:
   102
   Quantity:
   2
   Explain:
   "The order is placed into the queue and the stock is decreased."

7. CHECKOUT QUEUE
   Choose 7.
   Explain:
   "The queue uses FIFO, so the first order added is the first order
   processed."

8. PROCESS ORDER
   Choose 8.
   Explain:
   "This removes the first order from the queue."

9. RECENTLY VIEWED
   Choose 9.
   Explain:
   "This is the stack. The most recently viewed game appears first,
   demonstrating LIFO."

10. BST TRAVERSAL
    Choose 10.
    Explain:
    "In-order traversal visits the BST from smallest ID to largest ID."


11. ADD A NEW GAME
    Choose 11.
    Enter a unique ID, game name, category, publisher/brand, price, and
    initial stock quantity when prompted.
    Explain:
    "The program creates a new linked-list node dynamically and also
    inserts the game into the Binary Search Tree so it can be searched
    by ID."

12. VERIFY THE NEW GAME
    Choose 1 to show the inventory, then choose 3 and enter the new ID.
    Explain:
    "The new game appears in the inventory and is available in BST search."
